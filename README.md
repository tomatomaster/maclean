# MacLean

Mac用の重複ファイルクリーナーです。指定したフォルダ内の重複ファイルを検出し、不要なコピーを安全にゴミ箱へ移動することでストレージを解放します。

> **注意**: このプロジェクトはA.I.を活用して作成された実験的なソフトウェアです。利用は自己責任でお願いします。ファイルの削除操作を伴うため、重要なデータは事前にバックアップを取ることを強く推奨します。

## 機能

- **重複ファイル検出** - SHA-256ハッシュによる完全一致検出
- **高速スキャン** - ディレクトリ走査・ハッシュ計算の並列処理
- **ファイルタイプフィルター** - 画像 / 音楽 / 動画 / ドキュメント / アーカイブで絞り込み
- **最小サイズフィルター** - 1MB / 10MB / 100MB / 1GB 以上で絞り込み
- **キャンセル対応** - スキャン中いつでも中断可能、途中結果を表示
- **安全な削除** - ファイルはゴミ箱に移動（完全削除ではありません）

## 動作環境

- macOS（Intel / Apple Silicon）

## インストール

[Releases](../../releases) ページから最新のDMGをダウンロードしてください。

### 初回起動時の注意

本アプリはAppleの公証を受けていないため、初回起動時に警告が表示されます。

1. MacLean.appを**右クリック**して「開く」を選択
2. 確認ダイアログで「開く」をクリック

2回目以降は通常通り起動できます。

## 開発

```bash
# 依存パッケージのインストール
npm install

# 開発モードで起動
npm start

# macOS用ビルド（Universal）
npm run build:universal
```
